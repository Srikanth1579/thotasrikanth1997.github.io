# Srikanth Thota Portfolio Website

This is a starter DevOps and Cloud portfolio website built with plain HTML, CSS, and JavaScript.

## Template used

Template 1: DevOps Command Center

This template is designed for DevOps, Cloud, System Engineer, and Data Center roles. It includes:

- Hero section
- About section
- Skills section
- Experience section
- Project roadmap section
- Resume placeholder
- Contact section
- Responsive mobile navigation


## How to publish on GitHub Pages

1. Create a new GitHub repository named:

```text
thotasrikanth1997.github.io
```

2. Upload all files from this folder.
3. Go to repository Settings.
4. Open Pages.
5. Set source to Deploy from a branch.
6. Select the main branch and root folder.
7. Your website should become available at:

```text
https://thotasrikanth1997.github.io
```
